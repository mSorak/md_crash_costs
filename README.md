# Maryland Crash Costs

**[Live map → crash-cost-md.fly.dev](https://crash-cost-md.fly.dev)**

Interactive web map of police-reported motor vehicle crash comprehensive costs in Maryland (2024–2025). Explore per-capita costs by county, community, and census tract; filter by date and crash type; compare geographies in the dashboard.

Source code for the web application lives in [`crash_cost_app/`](crash_cost_app/). See that folder’s [README](crash_cost_app/README.md) for local development and [DEPLOY.md](crash_cost_app/DEPLOY.md) for Fly.io deployment.

Personal research project by [Matt Sorak](https://perfectnumbers.substack.com/). Not affiliated with any state agency.

**Note:** Crash data, cost pipeline notebooks, and analysis scripts are maintained separately and are not part of this repository.
